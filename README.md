# Boca Juniors PWA

Proyecto estático listo para GitHub Pages.

1. Crear un repositorio nuevo.
2. Subir todo el contenido de esta carpeta.
3. GitHub → Settings → Pages.
4. Deploy from a branch → `main` → `/ (root)` → Save.
5. Abrir la URL que entregue GitHub Pages.

Es una PWA independiente/de aficionado; no es una aplicación oficial del CABJ.
